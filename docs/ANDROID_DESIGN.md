# Android 设计基线

- 遵循用户指定的 Google Material 3：色彩角色、Roboto/系统中文字体、Material 图标、圆角曲面和状态反馈。
- 首版采用淡紫主色与柔和中性色；深色使用独立曲面层级，正文对比度优先。
- 主体信息从品牌、标题、概述、内容到操作逐层展开。内容最大宽度适配屏幕；小屏与大字体可以滚动，不挤压按钮文字。
- 触摸目标至少48dp，图标有清楚的可访问说明，选择状态通过语义和文本表达。
- 主题通过 DataStore 持久化，跟随系统为默认值；业务状态放 ViewModel，形变动画放可组合组件。
- Circle → Pill → Card 按项目规划书的阶段顺序独立实现和验收；进度来自业务阶段，不伪造百分比。
- UI 搜索建议用于参考；技能生成的推广网站布局和儿童字体不适用本产品。以用户指定的 Material 原生应用风格为准。
