# FragmentsPicker Android

Kotlin + Jetpack Compose + Material 3；最低 Android 8.0（API 26），编译和目标 SDK 36。使用固定的稳定依赖版本，应用主题支持浅色、深色和跟随系统，外观偏好通过 DataStore 保存。

在 Android Studio 打开本目录，或使用 Java 17+ 与 Android SDK 36 构建：

```powershell
.\gradlew.bat :app:assembleDebug :app:lintDebug
```

Android SDK 路径通过本机 `ANDROID_HOME` 或忽略的 `local.properties` 提供。APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。在已连接的模拟器上执行 `:app:connectedDebugAndroidTest`，验证启动、主题切换和重建后偏好保留。

已交付应用壳、主题、账号登录与注册、投喂、内容详情、历史回顾及 AI 对话页面。分享入口、每日 AI 总结等继续按独立模块交付。应用不包含阿里云、聊天供应商、数据库的凭据，所有云服务由后端调用。

## AI 对话页面

对话支持新会话、分页会话列表、较早问答、逐轮流式文字和服务器核验的来源卡片；卡片打开通用详情与原文。中间检索轮次文字会清除，最终正文以已保存回答为准，不解析模型生成的媒体链接。离开页面或进入后台暂停连接，保留加密请求；已收到消息 ID 时通过 GET 确认状态，未收到时手动确认沿用原创建/消息键。确认终态且清除本机记录成功后才允许下一条发送。历史请求与发送互斥，旧连接结束不会改变新连接的忙碌状态。

设备验证覆盖关闭模型的失败、页面重建后的同键确认与一条消息/会话去重；真实 DeepSeek 两轮空资料库问答验证保存结果与页面文字一致。教学样本验证使用真实 MySQL、本地 LangChain4j ONNX 与 DeepSeek，确认本人来源卡片、其他账号资料隔离、详情和原文跳转。样本的媒体对象是测试占位数据，封面回退占位图，不能据此宣称真实 OSS 播放通过。

真实模型设备测试需 `AI_CHAT_API_KEY` 等环境变量，显式运行 `Test-MySql.ps1 -AndroidAuth -AndroidChatLive -AndroidTestClass com.fragpicker.android.ChatLivePageIntegrationTest`。来源样本测试另加 `-AndroidKnowledgeFixture`，选择 `ChatSourcePageIntegrationTest`，且 Maven 测试过滤应包含 `AndroidKnowledgeFixtureTest`（不设置过滤时默认包含）。样本只写入脚本新建的隔离数据库，测试账号不进入生产代码或数据。普通 Android 验证关闭模型，真实模型测试默认跳过。

## 对话通信与未确认请求

`ChatStream` 使用后端 POST SSE，支持评论心跳、CRLF、多行 JSON 和 Unicode；限制事件、行与总流大小，截断事件报错，取消订阅断开连接。只有 HTTP401 触发一次令牌刷新，同一消息继续沿用 UUID 键。`PendingMessageVault` 使用 Keystore AES-GCM，加密保存问题、会话创建键、消息键及已收到的记录 ID；密文与后端地址、账号绑定，确认完成前保留请求。设备测试覆盖解析边界、加密/隔离；真实隔离后端测试通过关闭模型时的503以及同键重连读取已保存失败，确认数据库只存在一条消息。这项验证不调用付费模型，也不代表对话页面或真实模型回答已验收。

## 历史日历

回顾页提供以北京时间为基准的月历，切换月份、选择日期、回到今天；日期标记和已整理/处理中/失败数量来自真实日历接口。逐日列表每页20条，以记录 ID 游标继续加载。分类筛选明确作用于已加载资料，卡片显示封面、作者、摘要与真实处理状态，点击进入通用内容详情。快速切换日期会取消旧请求；导航返回保留选择，进入前台重新查询。真实后端设备测试使用23条记录验证数量、分页、空日期、详情跳转和重建后的月份恢复。每日 AI 总结将在后端持久化业务交付后接入。

## 内容详情与播放

投喂结果的“查看内容”进入详情页，展示作者、日期、摘要、要点、分类、关键词、保存备注和原始链接。逐句原文与时间要点使用后端游标分页；点击时间戳定位视频。待处理记录也可打开，尚未保存媒体时不开放播放按钮。系统返回或页面返回回到原导航页，重建后保留所选记录。

在线播放使用 Android 平台 VideoView，提供播放/暂停、进度拖动和刷新播放地址；后台暂停，关闭详情释放播放器。私有 OSS 签名地址仅驻留内存，不保存或输出，不向媒体主机传递后端 Bearer。封面下载限制8MiB、采样至1024像素，最多4个并发请求，失败时使用主题占位图。详情设备测试连接真实隔离后端验证待处理资料、禁用播放和重建恢复；播放器设备测试解码自制4秒 MP4，验证播放、暂停、时间跳转。上述测试不代表真实 OSS 视频联调已验收。

## 视频投喂

投喂页支持粘贴整段分享内容、填写可选备注和提交真实后台任务。提交结果不确定时重试相同内容沿用同一 UUID 请求键，后端继续执行来源去重。显示后台真实状态，每5秒轮询；切换页面、进入后台或退出登录会暂停状态轮询。此设备只保存与账号、后端地址绑定的最近任务 ID，重建后重新查询状态，任务不依赖 App 持续打开。鉴权仅在 HTTP 401 时串行刷新一次，不重放网络未知结果；请求取消会断开连接。投喂集成测试使用真实后端和隔离 MySQL，覆盖输入校验、入库、重建恢复和用户上下文隔离。

## 设置与外观

已登录后使用悬浮液态玻璃导航进入投喂、回顾、对话、设置。导航采用 [AndroidLiquidGlass / Backdrop](https://github.com/Kyant0/AndroidLiquidGlass) 1.0.0 的背景捕获、模糊和透镜折射，配合弹簧移动胶囊与 Material 图标。固定版本与当前 Kotlin 2.2.21 / Compose 1.9.4 兼容；Android 12 以下无实时模糊，Android 13 以下无透镜折射，保持可读的主题表面与完整导航功能。输入键盘打开时隐藏底部导航，退出账号时清理业务 ViewModel。导航测试覆盖四个标签、设置入口和手动深色主题。

主题切换位于设置页，提供浅色、深色、跟随系统三种模式；外观偏好通过 DataStore 保存。登录前也可从右上角设置按钮进入。账号信息和退出入口位于设置页，退出前二次确认。

## 登录与后端地址

任务状态组件 `ProcessingCard` 使用圆点 → 胶囊 → 信息卡动效：以中心展开宽度，再展示标题与不确定进度，完成或失败时先增加高度，再补足卡片宽度并显示正文和动作。显示真实阶段，不虚构处理百分比；遵循 Compose 系统动画比例。组件测试覆盖等待、完成、失败及动作点击。

Debug 默认使用 Android 模拟器宿主地址 `http://10.0.2.2:18080`；将本机后端的 `SERVER_PORT` 配置为18080，并启用 `database` profile。也可通过构建参数 `-PAPI_BASE_URL=https://your-backend` 改地址，支持必要的路径前缀。发布构建必须显式配置 HTTPS 地址，否则构建失败。明文 HTTP 仅在 Debug 对模拟器宿主与 loopback 开放，Release 禁止明文流量。

登录使用已有后端 `/auth/login` 和 `/users/me`，错误密码与网络失败有界面提示，提交期间禁用重复操作，密码不保存到偏好或重建状态。访问令牌仅在内存；刷新令牌用 Android Keystore AES-GCM 加密后保存，密文绑定当前后端地址，备份和迁移禁用。进程重启通过一次性刷新恢复会话，刷新串行执行；发送前删除旧令牌，无法确定是否成功的请求不重放，需重新登录。

## 真实登录集成测试

连接 API 26+ 模拟器并设置 `ANDROID_HOME`、`JAVA_HOME`，从仓库根目录运行：

```powershell
.\Server\scripts\Test-MySql.ps1 -AndroidAuth
```

测试脚本在随机 loopback 端口启动新的隔离 MySQL 与后端，自动把地址传入 Android 构建，验证错误密码、成功登录、页面重建、Keystore 加密和刷新恢复，最后关闭自己的测试进程。它不修改现有 MySQL 服务。普通 `connectedDebugAndroidTest` 未指定 `realBackend=true` 时跳过真实后端登录测试，仍可执行主题与 Keystore 测试。

## 注册页面

登录页面的“创建账号”进入注册；用户名、密码长度与后端约束一致，确认密码只在本机校验，不发送到后端。用户名冲突提示修改用户名，网络中断时提示结果未确认并允许返回登录。注册成功后显示确认页，点击“前往登录”预填用户名，密码需要重新输入；密码不保存到偏好或重建状态。上面的真实后端测试同时覆盖密码不一致、大小写用户名冲突、创建账号及用新账号登录。

## 退出登录

登录后的账号界面明确说明：退出会撤销当前账号所有设备的会话。退出期间禁用重复操作，调用 `/auth/logout` 后清理内存与本机加密凭据；访问令牌过期时串行执行一次刷新再退出。网络失败也清除本机凭据，并提示服务器撤销未确认；本机存储清理失败则保留重试提示，不报告退出成功。真实后端测试验证另一个设备的访问令牌立即失效、本机刷新凭据为空，以及重建后仍回到登录页。
